STADIA BRIDGE — WINDOWS x64

SINGLE EXE (easiest)
Download StadiaBridge.exe and double-click it. No Python or extraction needed.
The first launch may take a few seconds to unpack the bundled libraries.

PORTABLE ZIP
Extract this entire ZIP. Keep _internal beside StadiaBridge.exe, then run it.

BOTH VERSIONS
1. If ViGEmBus is not already installed, get the driver here:
   https://github.com/nefarius/ViGEmBus/releases/latest
   Reboot if requested. The driver is required and is installed separately.
2. Connect your Stadia controller using a USB data cable, or Bluetooth if your
   controller already has Bluetooth firmware.
3. Keep Stadia Bridge open while playing; minimizing is fine.

Windows sees an Xbox 360 controller through native XInput. Click Test in Windows
in the app to check it. Use Stop or close the app to remove the Xbox device.

The executable is unsigned. ViGEmBus is a retired dependency.
Rumble is forwarded where SDL supports it; press Test vibration to check.
Headset audio, Assistant and Capture are not forwarded.
If triggers register from light bumps, raise the Trigger threshold slider.
For duplicate input and troubleshooting, see README.md.
Dependency notices are accessible through the app's Licenses button.
